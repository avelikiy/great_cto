What holds it when nobody is looking
Four guards, each bought by a defect that shipped. Each fails the build — none of them warns.
contrast
every declared token pair,
every theme
A stylesheet used --muted in 61 places and declared it in none; the densest block on the page rendered at 2.62:1 and a person found it months later. Reads both themes — the light one went unchecked for months because the audit read only :root.
Also: a comment naming a token is not a declaration of it — prose about --bg-strong once became its value.
rendered-contrast
the pixel, not the token —
11 panels × 2 themes
The token audit has a blind spot the shape of a button: an element whose background comes from a token and whose colour comes from nowhere. Six controls rendered white-on-white at 1.00:1 while every declared pair was correct.
It also caught the third faux-bold element, which measuring the live board had missed — that headline's text depends on the data.
css-type-scale
every size on the ladder,
or excused by name
90 font-size declarations, all on the 14-step scale or on a named exception list. An exception needs a name, so drift cannot arrive as "just this once".
css-unused-selectors
does anything have
this class?
The question the other three never ask. 281 rules for classes no page rendered — 36% of a stylesheet — and eleven of fifteen contrast findings in that file were phantoms for those classes.
Three states: rendered / mentioned-in-code / unused. Only the last is a finding, because classList.add() is invisible to a grep of markup.
When a rule is broken on purpose
It goes on a named list with the task that owns it — never into a comment saying it was deliberate. The list may only shrink, and the guard names every entry that stopped occurring so the tightening actually happens rather than waiting for someone to check by hand. The board's list is currently empty.
One entry stays that is not a debt: .t-title measures 3.12:1 against the page and 5.98:1 against the terminal bar it actually sits on. An audit that reads one rule at a time cannot see the second number — so the reason is written beside the rule, or someone will "fix" a colour that is right.
