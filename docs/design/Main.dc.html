Direction ①
Not a mood. Five constraints a script can check, each one bought by a defect that shipped. Every number on this canvas was measured on the rendered page, not chosen.
1
No decorative shadow. No radius.
Depth comes from a 1px border and a change of surface, never from a blur. A shadow is admitted only as a ring — zero offset, zero blur — for focus and for the live pulse.
radius ≠ 0/50%/999px: 0
box-shadow: none: 15
rings kept: 5
2
Hierarchy by size, never by faux weight.
Geist Mono is vendored with a 400–500 axis. Asking it for 600 does not select a heavier cut — the browser strokes the glyph, and 600 and 700 render identically. That is a declaration the font cannot honour.
ink px, mono 32px
400 1473 · 500 1598
600 1926 · 700 1926
3
One token, one job.
A colour that is both a bed and an ink cannot be correct as both. --accent was asked to be readable text on 23 rules and a surface under light text on 13. Every such name is split, and the ink half is named for the bed it sits on.
accent / accent-text
status-review / …-text
on-solid · on-accent · on-status
4
Every text pair clears WCAG AA, measured on the pixel.
Not on declared token pairs — on the rendered element, against the background actually painted behind it. Six controls once rendered white-on-white at 1.00:1 while the token audit passed, because the colour that was wrong had never been declared.
floor 4.5 · large 3.0
panels × themes: 11 × 2
known below AA: 0
5
A rule with no guard is a preference.
Each constraint above is held by a test that fails the build. Where a debt is accepted it is named with the task that owns it, in a list that may only shrink — never a comment saying it was deliberate.

This canvas is drawn under its own rules: zero radius, no shadow, one mono family, hierarchy by size, and every pair on it above 4.5:1.
