# Native primary profile projection v1

Frozen before implementation under [ADR-046](../adr/ADR-046-native-plugin-activation.md).
This prepares a deterministic unsigned fixture profile. It does not select a
production manifest, establish runtime closure or grant native activation.

Done when: a pure producer and inverse validator preserve the exact bound source
hook inventory, root-bind every retained command, replace only the monolithic
SessionStart context/acquisition slot and select the local Node MCP entry. All
mutations, missing inputs and undeclared transformations must refuse.

Require the complete source manifest and the bound source-hook policy. Validate
all54 source hook identities before projection; do not accept a similarly named
or shortened manifest. Retain the53 other commands byte-for-byte after a fixed
root-binding prefix, with their event, matcher, order, timeout, async and status
metadata unchanged. No security/Stop/graph guard is removed or made permissive.
The prefix refuses missing or different CLAUDE_PLUGIN_ROOT and an explicitly
selected GREAT_CTO_NATIVE_PLUGIN_ROOT before any original command runs. Canonical
root/toolchain selection remains a future controller responsibility.

Replace only SessionStart/0/1 with the bounded selected context entrypoint. The
existing read-only context documents remain private host context. Preserve the
specialist-routing instruction: unavailable automatic changed-file guidance is
unknown and cannot justify omitting mandatory project reviewers or gates.

Explicitly removed from this future startup slot: cache search by newest version,
Git clone/pull, discovery refresh, updater/pruner, global managed sync, model
override writes, project copies/env generation, automatic codebase scan, global
preferences/pattern reads, credential-based provider quota fetching/refresh and
automatic Git-based reviewer scanning. Missing provider quota and reviewer scan
are unknown, never zero or evidence that work is safe/cheap. This is an intentional
future profile difference, not a claim of identical legacy convenience behavior.
Existing mandatory budget/graph/security/gate hooks stay intact. The six other
SessionStart commands and their unresolved write/runtime effects remain explicit
blockers until independently exercised; this projection is not a read-only
claim about the entire host startup.

Keep the server name, protocol and tool contract. Only its configuration becomes
command=node and a single plugin-relative server-native.mjs argument, with no
dotenv/global-CLI/npx fallback or URL override. Provider access occurs only via
an explicit later tool call; these checks make no provider/model request.

Return separate manifest and descriptor bytes with a fixed profile identifier,
source/policy/projected byte digests, fixed runtime-entry digests, source slot
count, replaced slot and removed-effect identifiers. Require both actual local
entrypoint byte buffers. The descriptor has authority NONE, activation
UNSUPPORTED; it is not a release, admission token or operator plan. No private
paths, environment values, credentials, task text or source command bodies in
the descriptor. Do not modify process.env, operator files or input buffers.

The validator independently reconstructs the exact expected transformation from
source/policy/runtime bytes, parses descriptor JSON strictly and compares exact
bytes, not merely versions or a self-reported PASS. Reject unknown/missing fields,
duplicate keys, extra MCP servers, altered guards/matchers/deadlines/order,
removed hooks, changed runtime bytes and rehashed malicious candidates. Returning
valid projection bytes must still report unsupported native activation.

Acceptance: deterministic generation, exact retained command/metadata comparison,
source nonmutation, all guard classes, MCP continuity, controlled actual shell
prefix refusal before a marker on missing/mismatched roots, success only on the
selected owned fixture roots, and adversarial recomputed-digest/descriptor cases.
No registration, real signing, package publication, operator activation or paid
calls. Real isolated native acceptance and production archive integration remain
separate work after source checks/review. Regenerate only standard architecture
module counters for new code. Keep earlier failed observations in evidence.
