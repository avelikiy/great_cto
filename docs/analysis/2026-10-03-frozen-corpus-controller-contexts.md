Each fixture commits the exact frozen baseline and adds one newline to the explicitly named mutable artifact. This is a whitespace-only changed-path routing stimulus. It is not a semantic repair, an accepted product change or one of the preregistered matched trials. Protected PROJECT/schema/decision bytes remain unchanged. Fixture Git uses empty templates, disabled hooks/signing/fsmonitor and suppressed system/global config, without changing operator Git configuration.

The harness loads the controller, specialist planner and routing rules from the extracted candidate, not the source controller. Delivered file inventory and actual graph bytes are hashed before construction and rechecked afterwards. A separate earlier whole-package check covers the exact archive, extraction and161-file local build parity; the harness inventory covers its delivered plugin root. Neither is runtime import instrumentation, reproducible compilation, signed host admission or a same-OS-user sandbox.
