Two faces, and the rule for choosing
The board is read by one person deciding what the machine may do next. Type here is not decoration — it is how a screen says this is an identifier you will paste as distinct from this is a sentence I am telling you. The choice is semantic, not aesthetic.

Three things the source says that the design did not intend
TYPE-1
Five rules ask Geist Mono for weight 600. It is vendored at 400–500.
Above the axis ceiling the browser synthesises the bold — a smeared outline, not a drawn weight. Affected: .layer-tag (×2), .delta, .agent-card .ac-name, .tl-actor. Repair: drop those to 500, or extend the vendored axis.
TYPE-2
The token named --serif contains no serif.
Its whole stack is sans — "Geist", "Space Grotesk", "Inter", -apple-system, sans-serif — and it is used nine times, on the KPI hero numerals. It is a display token doing display work correctly under a name that promises a contrast the page never had. Repair is the name: --display.
TYPE-3
Only the latin subset is vendored — by decision, and worth stating.
A Cyrillic project name or note leaves Geist mid-line and lands in the system stack, at a different weight and width. The UI is English-only and 52 KB of font is the reason; the constraint belongs in the spec so the mixed line is a known look rather than a bug someone re-discovers.
