# EVAL-qa-engineer-severity-accuracy.md

> Agent: qa-engineer · Generated by /gen-evals on 2026-06-04

## Scenario
The qa-engineer must assign correct P0/P1/P2 severity to findings, never let P0
issues pass as lower severity, and produce the substantive verdict format (not
boilerplate). Tests the explicit-gate + substantiveness patterns from v2.29.0.
